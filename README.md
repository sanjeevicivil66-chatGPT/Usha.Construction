# USHA CONSTRUCTION & ARCHITECT — Website

Responsive static website for the company. Built with HTML, CSS and vanilla JavaScript.

## Project files
- `index.html` — landing page, services, packages and WhatsApp enquiry form
- `assets/usha-logo.svg` — scalable company wordmark
- `AGENTS.md` — project engineering and Git workflow
- `index.yaml` — project inventory and content schema

## Render deployment
- Service type: Static Site
- Build command: leave empty
- Publish directory: `. ` (use a single dot: `.`)
- Production branch: `main`

## Enquiry funnel
The form validates required fields and opens WhatsApp with a pre-filled enquiry. It does not save submissions to a server.

## Before public launch
1. Confirm the phone number and office address.
2. Confirm package rates and written package inclusions.
3. Replace reference gallery images with actual company project photos.
4. Confirm the brand mark is the approved final logo.
5. Test WhatsApp on mobile and desktop.
